description: 멀티에이전트 구성 점검·자동 구성 (전역·프로젝트·모듈·시안)
---
인자: $ARGUMENTS (`fix`면 확인 없이 안전한 수정 적용)

1. `~/.claude/nomad/bin/nomad-doctor .` 실행. 표에서 ❌ · ⚠️ 행만 사용자에게 요약한다(✅는 개수만).
2. "자동으로 고칠 수 있는 것"이 있으면 목록을 보여 주고 확인받은 뒤(`fix` 인자면 바로) `nomad-doctor . --fix` 실행.
   자동 수정은 전역 재설치 · 프로젝트 init(기존 파일 보존·병합) · plan2spec 뿐이다. 파일 삭제는 하지 않는다.
3. ⚠️ 항목은 다음 행동을 제안만 한다 — AGENTS.md 템플릿 → "이 저장소에 맞게 채울까요?", 규칙 경로 불일치 → 실제 폴더로 paths 수정 제안,
   팀원 이름 충돌 → 지울지 사용자에게 묻기, 작업 표 예시 행 → `/plan`, 보안 레벨·Dependabot → `/secure setup`.
4. 전역 재설치가 일어났으면 "Claude Code를 다시 시작해야 팀원·스킬·훅이 새로 로드됩니다"라고 알린다.
