# stack-supabase — pitfalls (리뷰 1순위 체크리스트)

| # | 함정 | 증상·위험 | 확인 방법 |
|---|---|---|---|
| 1 | 테이블에 RLS 미설정 | 공개 키로 전 데이터 접근 | `enable row level security` 유무 |
| 2 | 정책이 `true` 로 열려 있음 | 사실상 무방비 | 정책 using/with check |
| 3 | 사용자 수정 가능 메타데이터를 인가 근거로 사용 | 권한 상승 | 정책의 JWT 클레임 출처 |
| 4 | update 정책에 with check 누락 | 소유권 이전·타 사용자 데이터로 변경 | update 정책 |
| 5 | 정책 컬럼 인덱스 없음 | 전 쿼리 지연 | 정책 조건 컬럼의 인덱스 |
| 6 | 적용된 마이그레이션 수정 | 환경 간 스키마 불일치 | git 이력의 기존 파일 변경 |
| 7 | 컬럼 삭제·타입 변경 시 앱 영향 미확인 | 런타임 오류 | Grep 컬럼명(apps/api · apps/web) |
| 8 | 서비스 롤 키 노출 | 전권 노출 | Grep `service_role`, 환경 변수 |
| 9 | 생성 타입을 수정 | 재생성 시 변경 소실 | 타입 파일 헤더·diff |
| 10 | 시드에 실데이터·키 | 정보 유출 | seed 파일 |
