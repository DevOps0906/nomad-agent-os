# stack-flutter — pitfalls (리뷰 1순위 체크리스트)

| # | 함정 | 증상 · 위험 | 확인 방법 |
|---|---|---|---|
| 1 | 결제·전송 버튼 중복 탭 | 중복 승인·중복 주문 | 요청 중 비활성화 + 멱등 키 |
| 2 | 통신 오류(승인 여부 모름)를 거절로 처리하고 재시도 | 이중 결제 | 같은 키로 상태 조회 · 망취소 먼저 |
| 3 | 금액에 `double` · `/` 사용 | 1원 오차, 합계 불일치 | Grep `double`, `/ ` in money 코드 |
| 4 | 화면 · 도메인에서 기기 직접 호출 | 가짜 기기로 테스트 불가 | Grep `Socket`, `MethodChannel` 위치 |
| 5 | 공통 코드에 업종·테넌트 이름 분기 | 확장마다 공통 코드 수정 | Grep `== 'cafe'` 류 문자열 분기 |
| 6 | 카드 · 전화번호 원문 로그 | 개인정보 노출 | Grep `print(`, `log(`, `debugPrint` 주변 값 |
| 7 | 인터넷 끊김 시 데이터 유실 | 승인됐는데 서버 기록 없음 | 로컬 outbox 저장이 서버 전송보다 먼저인지 |
| 8 | 위젯에 색 코드 · 고정 크기 | 테마 · 레이아웃 깨짐 | Grep `Color(0x`, 숫자 크기 상수 |
| 9 | 글꼴 런타임 다운로드 | 오프라인에서 화면 달라짐 | `google_fonts` 런타임 사용 금지, 자산 포함 |
| 10 | 비동기 후 `mounted` 미확인 | dispose 후 상태 변경 오류 | `await` 뒤 `context.mounted` / `ref.mounted` |
| 11 | prod 빌드에 fake 기본값 | 실매장에서 가짜 동작 | `--dart-define` 기본값, 개발 도구 노출 조건 |
| 12 | drift 스키마 버전 미증가 | 업데이트 후 앱 시작 실패 | `schemaVersion` · migration 단계 |
| 13 | 키오스크 잠금(Lock Task)을 개발 중 켬 | 기기에서 빠져나오지 못함 | dev 환경 잠금 기본 꺼짐 |
