# stack-fastapi — build & run

명령의 정본은 프로젝트 `AGENTS.md` 의 "명령" 표다. 아래는 일반적인 형태이며,
**프로젝트의 환경 관리 도구(venv · uv · poetry 등)를 확인한 뒤** 사용한다.

| 목적 | 일반 형태 | 비고 |
|---|---|---|
| 의존성 설치 | `<tool> install` / `pip install -r requirements.txt` | 잠금 파일이 정본 |
| 개발 서버 | `uvicorn <module>:app --reload` | 모듈 경로는 프로젝트 확인 |
| 린트·포맷 | `ruff check .` 등 | 프로젝트 도구 확인 |
| 타입체크 | `mypy .` / `pyright` | 설정 없으면 보고 |
| 테스트 | `pytest` | 외부 서비스는 의존성 오버라이드로 대체 |

## 테스트

- 라우터는 테스트 클라이언트로 요청·응답 형식·상태 코드를 검증한다.
- 인증은 의존성 오버라이드로 대체하고, 인가 실패(403)·미인증(401) 케이스를 포함한다.
- 외부 호출(Supabase 등)은 모킹한다. 테스트에 실제 키를 쓰지 않는다.
- 실행하지 못한 명령은 "미검증"으로 쓰고 통과로 간주하지 않는다.
