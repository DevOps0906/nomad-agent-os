# stack-fastapi — pitfalls (리뷰 1순위 체크리스트)

| # | 함정 | 증상·위험 | 확인 방법 |
|---|---|---|---|
| 1 | `async def` 안의 블로킹 호출(동기 DB 드라이버·`requests`·`time.sleep`) | 이벤트 루프 정체, 전체 지연 | 핸들러 내부 호출 목록 |
| 2 | 응답 모델 미지정 | 내부 필드·비밀 노출 | `response_model` 유무 |
| 3 | 인가 없이 인증만 확인 | 다른 사용자 데이터 접근(IDOR) | 소유권 검사 코드 |
| 4 | 서비스 롤 키를 기본 클라이언트로 사용 | RLS 우회 | 키 사용처 Grep |
| 5 | Pydantic v1/v2 문법 혼용 | 검증 동작 변경·런타임 오류 | 설치 버전과 import·메서드명 |
| 6 | CORS `*` + credentials | 자격 증명 탈취 위험 | CORS 설정 |
| 7 | 예외 메시지를 그대로 응답 | 내부 구조 노출 | 예외 핸들러 |
| 8 | 요청 처리 중 루프 안 쿼리(N+1) | 지연·DB 부하 | 반복문 안 호출 |
| 9 | 테스트가 실제 외부 서비스 호출 | 불안정·비밀 필요 | 의존성 오버라이드 유무 |
| 10 | 환경 변수 누락 시 조용한 기본값 | 운영에서 잘못된 동작 | 설정 모델의 필수 필드 |
