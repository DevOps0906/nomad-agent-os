# ux-patterns — 반드시 있어야 하는 구조를 빠뜨리지 않는다

## 1. 원칙
- **필수 요소는 도구가 검사한다**: 화면 표의 `유형`을 적으면 `plan2spec`이 [patterns.json](patterns.json)의 must 항목과 대조해 빠진 것을 🔴로 보고한다. must가 비면 기획이 끝난 것이 아니다.
- **기획 문서는 한 번만 해석한다**: `plan2spec`이 `03_SCREENS_UX.md`(+04 API · 05 데이터)를 `design/spec.json`으로 만든다. 이후 팀원은 문서를 다시 읽지 않고 `spec S-03`(화면 1개 ≈ 15줄)만 받는다.
- **그림·시안은 스크립트가 만든다**: 구조도(sitemap) · 흐름도 · 화면↔API↔데이터 연결도 · 화면별 와이어프레임 HTML(3구간)을 모델 토큰 0으로 생성한다. 바뀐 화면만 다시 만든다.

## 2. `03_SCREENS_UX.md` 형식 (이 표 이름·열 이름 그대로)
```markdown
## 화면
| ID | 화면 | 유형 | 경로 | 주된 일 | 구성 | 데이터 | API | 권한 | 다음 |
|---|---|---|---|---|---|---|---|---|---|
| S-01 | 매출 대시보드 | 대시보드 | /dashboard | 이번 달 매출 확인 | header, daterange:기간, stat:매출·주문·전월 대비, chart:일별 매출, table:최근 주문, updated, button:내보내기 | orders | A-01 | 로그인 | S-02 |
| S-02 | 주문 목록 | 목록 | /orders | 주문 찾기 | header, search, filter:상태·기간, table:주문번호·고객·금액·상태, pagination, button:주문 등록 | orders | A-02 | 로그인 | S-03 |

## 상태
| ID | 빈 | 로딩 | 오류 | 성공 |
|---|---|---|---|---|
| S-01 | 첫 주문 전 안내 + 주문 등록 버튼 | 지표 스켈레톤 | 다시 시도 버튼 | — |

## 흐름
| ID | 흐름 | 단계 |
|---|---|---|
| F-01 | 주문 처리 | S-01 → S-02 → S-03 |
```
- `구성` 블록: `header` `nav:항목·항목` `sidebar:…` `hero:…` `text:…` `stat:…` `chart:…` `table:열·열` `list:…` `card:…` `board:단계·단계` `form:필드·필드*` `button:라벨` `link:라벨` `search` `filter:…` `daterange` `pagination` `sort` `tabs:…` `breadcrumb` `steps:…` `activity` `updated` `export` `modal:…` `footer` `pricing` `faq` `empty` (모르는 블록은 회색 상자로 그린다)
- `다음`: 이 화면에서 갈 수 있는 화면 ID (구조도 · 드릴다운 검사에 쓰임). 해당 없으면 `—`.
- 상태 칸의 `—`는 "해당 없음"으로 인정한다. **빈 칸은 미정의**로 보고된다.

## 3. 벤치마킹 (새 제품·핵심 화면일 때, `docs/benchmark.md`)
| 제품 | 화면 | 반드시 있는 것 | 우리에게 없는 것 | 채택 여부 | 근거(URL·스크린샷 경로) |
|---|---|---|---|---|---|
- 비슷한 제품 3개, 핵심 화면 3개까지만. 근거 없는 "업계 표준" 주장은 쓰지 않는다(`미확인` 표시).
- 채택한 요소는 화면 표의 `구성`에 넣는다 → 다음 `plan2spec`부터 자동 검사 대상.

## 4. 유형별 필수 요소 (요약 — 정답은 patterns.json)
| 유형 | must | should |
|---|---|---|
| 대시보드 | KPI 요약 · 기간 선택 · 추세 차트/표 · 마지막 갱신 · 드릴다운 · 빈/로딩/오류 | 이전 기간 대비 · 내보내기 · 세그먼트 필터 · 할 일/알림 |
| 목록 | 검색 · 필터 · 표/목록 · 페이지 · 상세 이동 · 빈/로딩/오류 | 정렬 · 새로 만들기 · 일괄 작업 · 저장된 보기 |
| 상세 | 제목·상태 · 뒤로/경로 · 주요 작업 · 핵심 정보 | 관련 탭 · 활동 이력 · 404 |
| 폼 | 라벨 입력 · 제출 · 취소 · 로딩/오류/성공 | 필수 표시 · 임시 저장 |
| 보드 | 단계 열 · 단계 이동 · 필터 · 카드→상세 | 열별 합계 |
| 마법사 | 단계 표시 · 이전/다음 · 단계 입력 | 중간 저장 |
| 설정 | 구역 · 입력 · 저장 | 위험 작업 분리 |
| 로그인 | 입력 · 버튼 · 대체 링크 | 약관 링크 |
| 랜딩 | 히어로 · CTA · 푸터 | 실제 근거 · 가격 · FAQ |
