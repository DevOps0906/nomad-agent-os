# NOMAD CORE — 모든 AI 코딩 도구 공통 원칙 (Claude Code · ChatGPT Codex · Gemini CLI · OpenCode)

- 응답·문서·커밋 메시지는 한국어, 코드 식별자는 영어.
- UI는 항상 반응형 3구간: 모바일 ~767 / 태블릿 768~1199 / 데스크톱 1200~. 구간별 폰트 크기를 토큰으로 지정한다.
- 기술은 작업 시점의 최신 stable을 확인하고 버전을 적는다(예: "Tailwind CSS v4", "Next.js 16").
- README: 미완성 프로젝트는 `## 진행 현황`, 콘텐츠·문서가 있으면 그 아래 `## 콘텐츠 바로가기`를 반드시 쓴다(형식: `plan-docs` 원칙 7).

## 작업 4원칙
1. 생각 먼저: 가정을 드러내고, 해석이 여럿이면 고르지 말고 제시한다. 더 단순한 길이 있으면 말한다.
2. 단순하게: 요청한 것만. 한 번 쓰는 추상화, 요청 없는 설정, 일어날 수 없는 경우의 예외 처리 금지.
3. 외과수술식: 필요한 줄만 바꾼다. 옆 코드 "개선" 금지. 내가 만든 미사용 코드만 지운다.
4. 검증으로 끝낸다: 완료 조건을 실행 가능한 확인(테스트·명령)으로 바꾸고 통과할 때까지 반복한다.

- 위험도: 기획·디자인이 확정되면 개발 작업마다 위험·중요도·난이도 중 가장 높은 것으로 낮음/보통/높음을 정해 `tasks/README.md` 위험도 열에 적는다(위험도 없는 작업은 착수 금지). 워커 모델은 낮음=저가 · 보통=중간 · 높음=최상위(Claude: haiku/sonnet/opus)이고, 멀티에이전트 위임에도 반드시 명시한다. 높음(결제·인증·권한·마이그레이션·외부 계약·새 의존성)은 착수 전 계획 검토와 보안·계약 리뷰를 거친다.
- 연속 제작 큐: 영상 생성·블로그 포스팅처럼 오래 걸리거나 외부에 게시하는 작업이 이어 들어오면 겹쳐 실행하지 않고 `jobq add`로 줄 세운다. 종류와 상관없이 전체에서 동시 진행 최대 2건(`JOBQ_MAX`), 나머지는 모두 '대기'다. 진행 작업을 `jobq done`/`fail`로 마치면 빈 자리만큼 다음 대기 작업이 자동으로 '진행'이 되고, 에이전트는 지시를 기다리지 않고 출력된 그 작업을 바로 제작한다(`--cmd` 작업은 자동 실행).
- 보안: 비밀 커밋·로그 금지, lockfile 커밋, 새 의존성·노출 면·키 권한 변경은 `security-baseline`.

## 토큰 규칙 (도구 무관)
- **다시 읽지 않기**: 이미 읽은 파일은 다시 읽지 않는다. 바뀐 파일은 바뀐 줄만, 부분만 읽은 파일은 안 읽은 범위만. 새 세션은 `delta --changed`로 시작. Claude Code는 readguard 훅이 강제, 다른 도구는 `delta <파일>`. 문서·기획(.md)은 세션이 바뀌어도 장 단위로 기억한다: 전에 읽은 문서는 목차만 받고 바뀐 장만 읽는다(다른 도구는 `docmap <파일>` → 읽은 뒤 `docmap --mark`).
- 읽기: 구조 먼저(`codemap`), 필요한 함수·장만. 파일 전체 통독은 100줄 이하일 때만.
- 실행: 긴 출력 명령은 `q`(조용한 실행)로 감싼다 → 실패 줄과 요약만 본다. 전체 로그는 `.nomad/logs/`.
- 쓰기: 문서 내용을 지시문에 붙여 넣지 않는다. **경로 + 장 번호**만 넘긴다.
- 산출: 긴 결과는 파일로 쓰고 경로와 5줄 요약만 돌려준다.
- 그림은 Mermaid 텍스트만(SVG·draw.io XML 직접 생성 금지). 뼈대·미리보기·구조도·ERD는 도구로 만들고(`SDLC.md` 표) 모델은 내용과 판단만 쓴다.
- 단계가 끝날 때마다 `tasks/NOW.md`(단계·담당 모델·수정 파일·테스트 상태·남은 작업)를 갱신한다(끊기면 `handoff`). 작업 하나가 끝나면 `delta --checkpoint` 후 `/clear`.
- 도구 위치: `~/.claude/nomad/bin/` (PATH에 추가하면 이름만으로 실행).
