# NOMAD CORE — 모든 AI 코딩 도구 공통 원칙 (Claude Code · ChatGPT Codex · Gemini CLI · OpenCode)

- 응답·문서·커밋 메시지는 한국어, 코드 식별자는 영어.
- UI는 항상 반응형 3구간: 모바일 ~767 / 태블릿 768~1199 / 데스크톱 1200~. 구간별 폰트 크기를 토큰으로 지정한다.
- 기술은 작업 시점의 최신 stable을 확인하고 버전을 적는다(예: "Tailwind CSS v4", "Next.js 16").

## 작업 4원칙
1. 생각 먼저: 가정을 드러내고, 해석이 여럿이면 고르지 말고 제시한다. 더 단순한 길이 있으면 말한다.
2. 단순하게: 요청한 것만. 한 번 쓰는 추상화, 요청 없는 설정, 일어날 수 없는 경우의 예외 처리 금지.
3. 외과수술식: 필요한 줄만 바꾼다. 옆 코드 "개선" 금지. 내가 만든 미사용 코드만 지운다.
4. 검증으로 끝낸다: 완료 조건을 실행 가능한 확인(테스트·명령)으로 바꾸고 통과할 때까지 반복한다.

- 보안: 비밀 커밋·로그 금지, lockfile 커밋, 새 의존성·노출 면·키 권한 변경은 `security-baseline`.

## 토큰 규칙 (도구 무관)
- **다시 읽지 않기**: 이 대화에서 이미 읽은 파일은 맥락에 있다 — 다시 읽지 않는다. 읽은 뒤 바뀐 파일은 바뀐 줄만,
  부분만 읽은 파일은 안 읽은 범위만 offset/limit로. 새 세션은 `delta --changed`(체크포인트 이후 바뀐 파일 목록)로 시작한다.
  Claude Code는 readguard 훅이 강제한다(재읽기 차단, 바뀐 파일은 차단 메시지로 바뀐 줄만 전달).
  다른 도구(ChatGPT Codex·Gemini CLI·OpenCode 등)는 `delta <파일>`로 바뀐 줄만 본다.
- 읽기: 구조 먼저(`codemap`), 필요한 함수·장만. 파일 전체 통독은 100줄 이하일 때만.
- 실행: 긴 출력 명령은 `q`(조용한 실행)로 감싼다 → 실패 줄과 요약만 본다. 전체 로그는 `.nomad/logs/`.
- 쓰기: 문서 내용을 지시문에 붙여 넣지 않는다. **경로 + 장 번호**만 넘긴다.
- 산출: 긴 결과는 파일로 쓰고 경로와 5줄 요약만 돌려준다.
- 그림: 구조도·흐름도·ERD는 Mermaid 텍스트로. SVG·draw.io XML을 직접 생성하지 않는다. ERD는 `sql2erd`로 기계 생성.
- 생성: 문서 뼈대는 `plan-scaffold`, 디자인 미리보기는 `design-preview`, 구조도는 `deps2mmd`, ERD는 `sql2erd` — 모델은 내용과 판단만 쓴다.
- SDLC 단계·작업 단계가 끝날 때마다 `tasks/NOW.md`(단계·담당 모델·수정 파일·테스트 상태·남은 작업)를 갱신한다 — 모델 한도로 끊겨도 `handoff`로 이어 간다. 작업 하나가 끝나면 `delta --checkpoint` 후 맥락을 비운다(`/clear`).
- 도구 위치: `~/.claude/nomad/bin/` (PATH에 추가하면 이름만으로 실행).
